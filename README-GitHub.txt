طريقة التحديث:
1) ارفع index.html و manifest.json و sw.js و icon-192.png و icon-512.png إلى نفس مجلد الموقع على GitHub Pages.
2) افتح التطبيق من رابط GitHub Pages مرة واحدة.
3) ثبته على الشاشة الرئيسية.
4) بعد أي تعديل، ارفع الملفات الجديدة. عند فتح التطبيق سيحاول تحميل أحدث نسخة، وإذا ظهرت نسخة جديدة سيظهر زر "تحديث متاح".
مهم: بيانات المزرعة تظل محلية على الجهاز؛ تحديث الكود لا يمسحها. اعمل نسخة احتياطية JSON قبل التعديلات الكبيرة.
